### Requisitos Funcionales
| ID | Requisito | |
|:---|:---|
| RF-01 | El sistema debe permitir al líder crear y convocar un ensayo ingresando fecha, hora de inicio/término y lugar. | 
| RF-02 | El sistema debe emitir una notificación push automática a todos los integrantes de la banda al publicarse una nueva convocatoria. | 
| RF-03 | El sistema debe permitir a cada integrante marcar su voto de asistencia ("Asisto" o "No asisto") y, en caso de asistir, seleccionar el rol instrumental con el que participará (ej. Guitarra, Bajo, Batería, Teclado o Voz). |
| RF-04 | El sistema debe calcular el quórum de confirmación evaluando que se alcance el 75% general y priorizando la presencia mínima de instrumentos base sobre la sección vocal. |
| RF-05 | El sistema debe confirmar el ensayo y fijarlo en el calendario de la banda de manera automática una vez validado el quórum del 70% y la cobertura instrumental requerida. | 
| RF-06 | El sistema debe notificar al líder en caso de no alcanzar el quórum general o faltar roles instrumentales prioritarios, habilitando la opción directa de reagendar. | 
| RF-07 | El sistema debe enviar una notificación automática de recordatorio el día del ensayo a los integrantes confirmados. | 
| RF-08 | El sistema debe permitir al líder ingresar y guardar la minuta técnica post-ensayo con las canciones practicadas y las observaciones de arreglos/interpretación por instrumento. |
| RF-09 | El sistema debe desplegar a todos los miembros de la banda el historial de ensayos anteriores con sus acuerdos y canciones registradas. |
